# WealthPulse - App Store Listing

## App Name
**WealthPulse**

## Subtitle
Personal Finance Manager

## Description

Take control of your finances with WealthPulse - the all-in-one personal finance app designed for the US market.

### Key Features:

**Dashboard**
- Wealth Health Score (0-100) based on your financial habits
- Monthly income vs. expenses overview
- Quick access to add transactions
- Net worth tracking across all accounts

**Smart Budgeting**
- Follow the proven 50/30/20 budgeting rule
- Set custom category budgets
- Track spending progress with visual indicators
- Get notified when approaching limits

**Goal Center**
- Create savings goals for anything
- Track progress with beautiful visual rings
- Set deadlines and milestones
- See projected completion dates

**Investment Tracker (Premium)**
- Monitor your investment portfolio
- Track stocks, ETFs, and mutual funds
- Calculate returns and performance

**Tax Center (Premium)**
- Estimate federal and state taxes
- Track quarterly payments
- Support for W-2 and 1099 income

**Additional Features**
- Face ID / Touch ID security
- Light and Dark theme support
- Multiple currency support
- Recurring transaction tracking
